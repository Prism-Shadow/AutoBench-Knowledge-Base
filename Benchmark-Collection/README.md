# Benchmark Collection（第一阶段调研提交）

本目录用于汇总 AutoBench 第一阶段各领域高质量 Benchmark 与相关方法论文的调研结果。

## 提交方式与要求

1. **任务认领**：先在 [AutoBench 第一阶段调研与任务认领表](https://docs.qq.com/sheet/DTVhCZ1RjVUJreGN5?tab=BB08J2) 中填写认领序号与姓名（一人可认领多个方向，ddl: 12月3日）。
2. **Benchmark 的质量和论文要求**（满足其一即可）：
   - 高引用、高影响力
   - 知名团队、大厂发布的 benchmark
   - LLM tech report 里常用的评测 benchmark
3. **提交内容**（以下至少有一项）：
   1. 论文链接
   2. Tech blog 的链接
   3. X 上介绍工作的链接
   4. Hugging Face 链接
   5. benchmark 的 GitHub 仓库链接
4. **提交方式**：编辑下方对应序号的 Markdown 文件并填入表格后，通过提交 **Pull Request (PR)** 的方式合到本仓库来进行提交。
