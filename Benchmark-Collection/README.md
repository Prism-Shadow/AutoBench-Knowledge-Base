# Benchmark Collection（第一阶段调研提交）

本目录用于汇总 AutoBench 第一阶段各领域高质量 Benchmark 与相关方法论文的调研结果。

## 提交方式与要求

1. **任务认领**：先在 [AutoBench 第一阶段调研与任务认领表](https://docs.qq.com/sheet/DTVhCZ1RjVUJreGN5?tab=BB08J2) 中填写认领序号与姓名（一人可认领多个方向）。
2. **质量要求**：
   - 高引用、高影响力
   - 大公司在用，或者大公司出品，或者大公司的 Tech Report 里用过这个 Benchmark
3. **提交内容**：点击下方对应序号的 Markdown 文件，在表格中填入：
   - **论文链接**（必填）
   - **Hugging Face 数据集仓库**（链接，如无则填 `-`）
   - **GitHub 仓库**（链接，如无则填 `-`）
   - **影响力说明**（简述引用量、出品机构或使用该 Benchmark 的 Tech Report）
