# AutoBench Knowledge Base

AutoBench（A System for Synthesizing High-Quality Benchmarks）的知识库仓库。

当前处于第一阶段调研与收集期，各领域高质量 Benchmark 与相关论文的提交统一存放在 [`Benchmark-Collection/`](./Benchmark-Collection/) 目录下，后续将在此基础上逐步沉淀并拆分为 `Judge KB` 与 `Builder KB`。
